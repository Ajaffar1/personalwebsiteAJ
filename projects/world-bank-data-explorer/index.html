World Bank data explorer

A university team project that turns World Bank development indicators into an interactive desktop application, connecting data retrieval with visual exploration.

Explore the source on GitHubAll projects

From indicators to an interface

Built as a CS2212 course project in 2021, the application helps users browse and visualize development data. It connects a Java desktop interface to data retrieval and parsing, making a large public dataset easier to explore.

Inside the application

The source includes HTTP data extraction and JSON parsing, alongside separate viewers for line, bar, area, scatter, bubble, and pie charts. This structure separates the work of getting data from the work of presenting it, giving each visualization its own place in the application.

A collaborative course project

The repository credits a university team including Ahmed Jaffar. It is shared here as a learning project and an example of working across application structure, external data, and chart-based interfaces. The repository includes instructions for running the Java application.
