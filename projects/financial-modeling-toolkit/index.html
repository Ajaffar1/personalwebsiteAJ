Financial Modeling Toolkit

A Python research library connecting financial forecasts and DCF valuation with portfolio construction, risk analysis, and quantitative investment research.

Explore the source on GitHubAll projects

Finance, expressed in code

The toolkit combines integrated financial forecasts, discounted cash flow valuation, scenario analysis, and audit checks. It makes assumptions explicit and supports year-specific operating drivers, including capital expenditure.

Research capabilities

The public Python package includes portfolio allocation and backtesting, risk and factor analysis, options and fixed-income analytics, stochastic valuation, and advanced statistical research. Optional NumPy, SciPy, and openpyxl dependencies support quantitative calculations and Excel workflows.

Current scope

This is a modeling and research library. Examples use synthetic data, and results depend on assumptions that need validation. It has no live market feeds, broker connections, or automatic trading. Excel exports contain calculated values rather than live formulas.
