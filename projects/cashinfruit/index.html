CashinFruit personal finance prototype

A HackWestern 8 team project exploring a simple personal finance experience: connecting bank-account data and bringing spending information into one place.

Explore the source on GitHubAll projects

The product idea

CashinFruit explores how a connected account experience can help users understand their finances. Built in a hackathon setting, the project focuses on a working product concept and the systems needed to move data from an integration into an application interface.

Inside the stack

The public source includes a React frontend and a Node.js backend using Express. The frontend uses the React Plaid Link integration, while the backend includes the Plaid SDK, Axios, and Mongoose among its dependencies. This connects interface work with server-side integration and data handling.

Built as a team prototype

The repository identifies CashinFruit as a HackWestern 8 project and credits a team including Ahmed Jaffar. It is a hackathon prototype, rather than a currently supported financial service. The source is linked below for people interested in the architecture and implementation.
